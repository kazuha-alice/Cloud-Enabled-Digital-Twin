# Cloud-Enabled Digital Twin (Temporary Test Build)

## ⚠️ Project Status: Deprecated

This repository represents an **early experimental prototype** of a Cloud-Enabled Digital Twin system.

> 🚫 This project is **no longer functional**
> 🚫 All backend APIs have been **removed from AWS**
> 🚫 No maintenance or updates will be provided

---

## 📖 Overview

This project was developed as a **temporary validation layer** during the early phase of a larger Digital Twin initiative.

It was built as part of work associated with:

* Accenture
* Development environment and collaboration within the Indian Institute of Technology Madras

<p>The system architecture consisted of multiple internal layers and integrations, making it significantly different from conventional web-based Digital Twin implementations, as it was built using Unity 6.</p></br>


## 🎯 Purpose

This prototype was created strictly for **pre-production validation**, including:

* Triggering remote test machines
* Measuring **latency and response time**
* Validating **cloud-to-system communication pipelines**
* Testing API orchestration before system migration

This was a **beta/testing layer**, not a production system.


## 🧪 Tech Stack (Prototype Phase)

* **Frontend:** HTML, JavaScript
* **Backend:** AWS APIs *(now removed)*
* **Role:** API-driven orchestration and system testing


## ❌ Current State

This repository is **non-functional** due to:

* Complete removal of AWS APIs
* Migration to a different internal architecture
* Decommissioning after successful validation

This was a **temporary test build** and intentionally not maintained.
